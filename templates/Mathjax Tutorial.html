MathJax Tutorial - Complete Guide

MathJax is a powerful JavaScript library for displaying mathematical notation on web pages. It supports LaTeX, MathML, and AsciiMath input and renders beautiful, scalable math in all modern browsers.

1. Including MathJax in Your Page

Add this script in your <head> to load MathJax from CDN:

<script src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js" id="MathJax-script" async></script>
Note: The async attribute loads MathJax asynchronously, so it doesn't block page rendering.

2. Writing Math

MathJax supports two main ways to write math:

  • Inline math: Use \(...\) or $...$ to include math within text.
  • Display math (block math): Use \[...\] or $$...$$ to display math on its own centered line.

Examples

Inline math example: When \(a \ne 0\), the quadratic formula is \(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\).

Display math example:
\[ \int_a^b f(x) \, dx = F(b) - F(a) \]

3. Common MathJax LaTeX Commands

  • \frac{numerator}{denominator}: Fractions
  • \sqrt{expression}: Square roots
  • \sum_{i=1}^n: Summations
  • \int_a^b: Integrals
  • \alpha, \beta, \gamma, \pi: Greek letters
  • \sin, \cos, \log, \exp: Common functions

4. Configuring MathJax

You can customize MathJax behavior by adding a configuration script before loading MathJax.

<script>
window.MathJax = {
  tex: {
    inlineMath: [['$', '$'], ['\\(', '\\)']],
    displayMath: [['$$', '$$'], ['\\[', '\\]']],
    macros: {
      RR: '\\mathbb{R}',
      bold: ['{\\bf #1}', 1]
    }
  },
  options: {
    skipHtmlTags: ['script', 'noscript', 'style', 'textarea', 'pre']
  }
};
</script>
<script src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js" id="MathJax-script" async></script>

This example:

  • Defines inline and display math delimiters.
  • Adds custom macros \RR and \bold.
  • Prevents MathJax from processing inside certain HTML tags.

5. Using MathJax in JavaScript

If you dynamically add math content to your page, call MathJax.typeset() to re-render math:

// Add math to a div
const div = document.getElementById('dynamicMath');
div.innerHTML = 'Here is some math: \\( e^{i\\pi} + 1 = 0 \\)';
// Rerender math in the document
MathJax.typeset();

6. Troubleshooting Tips

  • Make sure MathJax script is loaded before rendering math.
  • Use the correct delimiters (\(...\) for inline, \[...\] for display).
  • If math doesn’t render, call MathJax.typeset() after dynamically adding math.
  • Check browser console for errors.

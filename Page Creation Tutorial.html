Astropedia Web Tutorial

Learn HTML, CSS & JavaScript to build your own astronomy encyclopedia website

1. HTML Basics

HTML is the foundation of every webpage. It tells the browser what to show and how to structure content.

Example of a simple HTML page structure:

<!DOCTYPE html>
<html>
  <head>
    <title>Astropedia</title>
  </head>
  <body>
    <h1>Welcome to Astropedia</h1>
    <p>Your encyclopedia about space!</p>
  </body>
</html>

Try it yourself: Create a simple HTML page

2. CSS Styling

CSS controls how your page looks — colors, fonts, layout, spacing, and more.

Example: Adding color and center alignment

<style>
  body {
    background-color: #000022;
    color: #ffdd00;
    text-align: center;
    font-family: Arial, sans-serif;
  }
</style>

Try it yourself: Style your Astropedia page

3. JavaScript Interactivity

JavaScript adds behavior — you can respond to clicks, update content dynamically, and more.

Example: Click a button to show an alert

<button onclick="alert('Hello from Astropedia!')">Click me</button>

Try it yourself: Interactive Button

4. Build a Planet Card

Combine HTML and CSS to create a nice card about a planet.

<div class="planet-card">
  <img src="https://upload.wikimedia.org/wikipedia/commons/9/97/The_Earth_seen_from_Apollo_17.jpg" alt="Earth" />
  <h3>Earth</h3>
  <p>Our home planet, the third from the Sun.</p>
</div>

Try it yourself: Planet Card

5. Layout with Flexbox

Flexbox helps you arrange items in rows or columns easily.

<div class="container">
  <div class="planet">
    <img src="https://upload.wikimedia.org/wikipedia/commons/9/97/The_Earth_seen_from_Apollo_17.jpg" alt="Earth">
    <h3>Earth</h3>
  </div>
  <div class="planet">
    <img src="https://upload.wikimedia.org/wikipedia/commons/thumb/0/02/OSIRIS_Mars_true_color.jpg/1024px-OSIRIS_Mars_true_color.jpg" alt="Mars">
    <h3>Mars</h3>
  </div>
</div>

Try it yourself: Flexbox Layout

6. JavaScript: DOM Manipulation

Change page content dynamically using JavaScript.

<button id="btn">Change Text</button>
<p id="text">This is original text.</p>

<script>
  document.getElementById('btn').addEventListener('click', () => {
    document.getElementById('text').textContent = 'Text changed by JavaScript!';
  });
</script>

Try it yourself: Change text on button click

7. Responsive Design

Make your site look great on phones, tablets, and desktops with media queries.

<style>
  body {
    background: #203a43;
    color: #ffd166;
  }
  .container {
    width: 80%;
    margin: auto;
    background: #0b3d91;
    padding: 1rem;
  }
  @media (max-width: 600px) {
    .container {
      background: #ffb400;
      color: #142850;
    }
  }
</style>

Try it yourself: Change background color on small screens

8. Forms & Validation

Collect user input and validate it before submission.

<form>
  <label for="email">Email:</label>
  <input type="email" id="email" required />
  <button type="submit">Submit</button>
</form>

Try it yourself: Simple email form

9. Embed NASA Video

You can embed videos or other content using <iframe> tags.

<iframe width="560" height="315" src="https://plus.nasa.gov/video/space-out-moon-phases/" 
title="NASA Video" frameborder="0" allowfullscreen></iframe>

Try it yourself: Embed a NASA video

10. Simple CSS Animation

Animate your page elements for a lively effect.

<style>
  .rotating-star {
    display: inline-block;
    font-size: 3rem;
    color: #ffd166;
    animation: spin 4s linear infinite;
  }

  @keyframes spin {
    from { transform: rotate(0deg); }
    to { transform: rotate(360deg); }
  }
</style>
<div class="rotating-star">⭐</div>

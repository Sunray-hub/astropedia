# 🌌 Astropedia

**Astropedia** is a Flask-based astronomy platform designed to make exploring space and astronomy information easier and more interactive.

The website combines multiple astronomy data sources and tools to provide information about **near-Earth asteroids, space weather, astronomy news, and astronomical topics**. It also includes a search system powered by Wikipedia and features that allow users to create, view, search, and edit their own astronomy pages.

## 🚀 Features

* 🌍 **Near-Earth Asteroid Data** — Displays asteroid names, hazard status, estimated diameter, velocity, and miss distance using NASA's APIs.
* ☀️ **Space Weather** — Provides data about solar flares, CMEs, solar energetic particles, geomagnetic storms, and other solar events.
* 📰 **Space News** — Fetches recent articles from the Spaceflight News API.
* 🔭 **Astronomy Search** — Search for astronomy topics and get summaries from Wikipedia.
* 📚 **Britannica Integration** — Generates Britannica search links for searched topics.
* ✏️ **Create Pages** — Users can create custom astronomy pages with HTML and CSS.
* 🔧 **Edit Pages** — Existing custom pages can be searched and edited.
* 🔎 **User Page Search** — Search through locally created astronomy pages.
* 🔊 **Text-to-Speech** — Generates an introductory speech using `pyttsx3`.
* 📱 **Responsive Interface** — Includes responsive navigation for smaller screens.

Astropedia aims to create a simple, accessible place where anyone can **learn about astronomy, explore current space data, and create their own astronomy content**.

> **Explore the universe. Learn about space. Create your own knowledge. 🚀**
